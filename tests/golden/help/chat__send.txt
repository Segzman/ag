usage: ag chat send [-h] [--job {mechanical,implement,review,debug,plan,hardest}]
                    [--command COMMAND] [--timeout TIMEOUT] [--stall-s STALL_S]
                    [--request-id REQUEST_ID] [--force] [--notify-done] [--verify CMD]
                    [--escalate MODEL[,MODEL...]] [--verify-timeout S]
                    name [text ...]

positional arguments:
  name
  text

options:
  -h, --help            show this help message and exit
  --job {mechanical,implement,review,debug,plan,hardest}
                        record job type in events
  --command COMMAND     opencode native custom command (message becomes its args)
  --timeout TIMEOUT     hard backend runtime limit in seconds (0=unlimited, default 1800); starts
                        after guard acquired, lock wait excluded
  --stall-s STALL_S     stall watchdog seconds for this turn (0 = off; default:
                        agent/AG_STALL_S/backend default)
  --request-id REQUEST_ID
                        idempotency key: replay returns the original result
  --force               bypass budget limits once (logged)
  --notify-done         write a notification when the turn finishes
  --verify CMD          after the turn, ag runs trusted CMD via sh -c in the agent workdir and
                        records {cmd,exit,tail(40 lines)} in the result + a [verify] row in the
                        chat log (never from the agent's reply)
  --escalate MODEL[,MODEL...]
                        needs --verify: on failed verify/turn, retry the same session on each next
                        model (one-turn override, roster unchanged); result gains escalation[]
  --verify-timeout S    verify command timeout in seconds (default 600)
